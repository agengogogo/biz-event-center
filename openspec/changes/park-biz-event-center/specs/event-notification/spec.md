# Spec Delta

## Purpose

依据订阅与规则通过多种通道推送通知，使用模板渲染内容，并记录投递结果以供追踪与重试。

## ADDED Requirements

### Requirement: 通知通道

系统 MUST 支持至少一种外部通知通道（短信、企业微信、Webhook、邮件），并允许按订阅选择使用的通道。

#### Scenario: 通过配置的通道发送通知

- **WHEN** 触发通知且对应订阅已配置通知通道
- **THEN** 系统通过该通道发送通知

### Requirement: 通知模板渲染

系统 MUST 支持使用可复用模板渲染通知内容，模板可以引用事件字段。

#### Scenario: 使用模板渲染通知

- **WHEN** 通知使用模板发送
- **THEN** 系统将事件字段渲染进模板生成通知内容

### Requirement: 投递结果跟踪

系统 MUST 记录每次通知的投递状态与失败原因，并支持对失败通知重试或人工重发。

#### Scenario: 记录投递结果

- **WHEN** 通知发送流程结束
- **THEN** 系统记录成功或失败状态及失败原因

#### Scenario: 失败通知可重发

- **WHEN** 管理员对失败的通知发起重发
- **THEN** 系统重新执行该通知的投递
