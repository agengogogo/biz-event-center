# Spec Delta

## Purpose

对园区事件进行统计聚合与实时态势展示，提供与具体前端无关的统计和态势数据 API。

## ADDED Requirements

### Requirement: 事件统计聚合

系统 MUST 按事件类型、来源、严重级别、园区/位置和时间维度对事件进行统计聚合。

#### Scenario: 按维度统计事件

- **WHEN** 请求某个时间范围内按指定维度聚合的统计
- **THEN** 系统返回对应维度的事件数量

### Requirement: 实时态势查询

系统 MUST 提供实时或近实时的活跃事件与告警态势查询。

#### Scenario: 查看当前活跃态势

- **WHEN** 客户端请求当前的活跃告警态势
- **THEN** 系统返回当前未关闭的高优先级事件

### Requirement: 看板数据服务

系统 MUST 提供与客户端无关的看板数据查询 API，管理前端运营大屏或其他已授权客户端均通过该 API 获取统计与态势数据。

#### Scenario: 客户端通过 API 获取看板数据

- **WHEN** 任一已授权客户端发起看板数据请求
- **THEN** 系统返回渲染大屏所需的统计与态势数据
