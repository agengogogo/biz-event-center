# Spec Delta

## Purpose

管理事件订阅及其过滤与转换规则，定义哪些事件在什么条件下、以何种结构投递给哪些目标。

## ADDED Requirements

### Requirement: 订阅生命周期管理

系统 MUST 支持创建、修改、启用、停用和删除订阅，每个订阅包含主题、投递目标与状态。

#### Scenario: 创建并启用订阅

- **WHEN** 管理员创建订阅并将状态设为启用
- **THEN** 匹配该订阅主题的事件开始被投递

#### Scenario: 停用订阅

- **WHEN** 管理员将订阅状态设为停用
- **THEN** 系统不再向该订阅投递新事件

#### Scenario: 删除订阅

- **WHEN** 管理员删除一个订阅
- **THEN** 系统移除该订阅且不再对其进行路由

### Requirement: 过滤与转换规则

系统 MUST 支持为订阅配置过滤条件与转换规则，仅投递满足条件的事件，并允许在投递前调整事件负载结构。

#### Scenario: 条件不匹配被跳过

- **WHEN** 事件不满足订阅的过滤条件
- **THEN** 系统不向该订阅投递该事件

#### Scenario: 应用转换规则

- **WHEN** 事件满足过滤条件且订阅配置了转换规则
- **THEN** 系统按规则转换事件负载后再投递
